# SRTP Project Stage 1

Unified first-stage workspace for code LLM pruning reproduction.

Main paths: `data/`, `methods/`, `workflows/`, `results/`, `docs/`, `environment/`, `tests/`, and `third_party/`.

The method set contains Flab-Pruner, LLM-Pruner, SliceGPT, LaCo, Magnitude, Wanda, DSnoT, OWL, SparseGPT, MaskLLM, Pruner-Zero, and FLAP. Member names are used only as owner metadata.
