# Methods

Each method directory contains the local adapter or reproduction notes for one Stage-1 route. The authoritative status table is `results/status/methods.csv`; it is regenerated from run evidence and method metadata rather than edited by hand.

The 12 tracked routes are:

- Flab-Pruner
- LLM-Pruner
- SliceGPT
- LaCo
- Magnitude
- Wanda
- DSnoT
- OWL
- SparseGPT
- MaskLLM
- Pruner-Zero
- FLAP

Owner metadata is retained for accountability, while benchmark conclusions come only from registry and evidence files.
